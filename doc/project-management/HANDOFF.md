## Keeping the Work plugin in step

The core reaches the plugin through links in its source and through the build, so run `scripts/build_work_plugin.py` after any core change. The build stamps a digest of the content into the version, so a change always gives a new version and an installed copy never goes stale silently. Any new file in the plugin needs an allowlist update in `tests/test_work_plugin.py`. The model guide is shared with the Claude plugin, so an edit reaches both. Run `scripts/work_host_check.py` after an app update, because host behavior is measured on one version.
